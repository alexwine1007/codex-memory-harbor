# Memory Harbor · 记忆港｜先找到真正需要的人

[English](README.md) · [安全试用](TRY.md) · [发布文案](POSTS.md) · [两周执行清单](PLAN.md)

**Codex 的旧子任务和素材占满了 Mac？安全搬到外盘，外盘在线时仍能沿原路径读取。**

我们想先找到 5–10 位确实遇到这个问题的人，一起验证是否好用，而不是追求空泛的 Star 数。

## 先体验，再决定

1. 先[只读盘点](TRY.md#1-read-only-inventory)，不移动你的文件。
2. 用工具新建的[可丢弃样例](TRY.md#2-disposable-byte-transaction-trial)，走一遍停泊、原路径读取和恢复。
3. 在仓库 **Issues → New issue → Beta trial feedback** 中反馈遇到的问题。不上传私人聊天、日志、完整路径或凭据。

这是 **macOS 第三方源码测试版**。没有公开的 Apple 公证安装包；运行需要 Python 3.9+。不迁移整个活跃工作区，不是通用备份，也不保证 Codex 自动记住所有对话。首次真实操作请保留本地副本，分别测试重启、重挂载与恢复。拔盘时原件暂时不可读。

## 为什么这样做

先把使用价值和试用过程讲清楚，在相关社区帮助真实遇到问题的人，再根据反馈改进。这与 [Open Source Guides 的建议](https://opensource.guide/finding-users/)一致。Show HN 要求提供[实际可试用的东西](https://news.ycombinator.com/showhn.html)，不能只是报名页，也不能组织刷票。
