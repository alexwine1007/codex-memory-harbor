# 0.4.6-beta.1 verification — 2026-10-12

## Scope

This release implements the single workbench, native desktop material, English/Simplified Chinese presentation and source-distribution documentation. Personal project assets and history were not migrated, released or restored by the agent. Actual user batches remain user-controlled.

## Automated gates

- 107 tests passed with `MEMORY_HARBOR_TEST_VOLUME` enabled on the attached exFAT drive. Physical tests use disposable scratch files, not user data; they verify original-path reads, expected hashes, release and restore.
- Pure JavaScript model tests exercise 40 large history candidates without the previous arbitrary selection cap, protected-history exclusion, oldest-modification sorting and exact membership of multiple frozen media plans.
- Localization tests check both dictionaries, interpolation parity, static keys and translated progress. Fixture settings are isolated from real user preferences.
- JavaScript and shell syntax, both Swift typechecks, signed native builds, strict nested bundle verification and installed-Skill/source comparison passed.
- The official Skill validator was unavailable because PyYAML was absent. An independent Ruby YAML/frontmatter validation passed; this is not a claim that the unavailable validator ran.

## Browser user path

Using the actual API-backed dashboard with disposable files and isolated preferences:

1. Star a project: media inventory becomes unavailable; unstar it and inspect media on demand.
2. Select a media file, open the exact confirmation and verify that local-copy retention is checked by default.
3. Confirm docking: the terminal progress reaches 100%, and retained-copy completion explicitly reports no local copies removed.
4. In Docked, inspect the receipt-backed file, select it and restore after a second confirmation. Completion reaches 100%; the ordinary source file is again eligible in the media inventory.
5. Switch language and appearance without resetting destination or selection. Search/clear and narrow layout were exercised; browser console warnings/errors were absent.

Desktop and 390-pixel layouts, dark/light appearance and both languages were visually reviewed. Public screenshots contain disposable test data. WebKit's native short popup styling was observed in the installed helper and corrected with explicit native-appearance reset while retaining the accessible select element.

Project rows distinguish history-only bytes, inspected scope and unscanned media; absence of an inventory is not reported as a zero-byte project.

## Installed Mac app

The installed app reports `0.4.6-beta.1`; its stable signing identity and strict signature verification passed. The real helper displayed the workbench, current internal free space, mounted destination and four history candidates. Returning to desktop rendered the native card with 205/205 docked histories accessible. The card's native material and spacing were visually reviewed. Helper/server lifecycle and the saved desktop placement use the existing implementation rather than a new timer.

This verifies display and read-only access, not a new private-history batch, physical unplug/remount or Codex cold resume for this release.

## Performance boundary

The read-only local-index benchmark measured 1.094 ms median and 2.216 ms p95 over 40 iterations. A 778-session metadata scan took 2.459 seconds; the catalog was 8,425,472 bytes. These are local index/scan observations, not foreground latency under an active transfer, a storage ceiling or a promise for other machines.

The compact card remains event-driven; media inventory is on demand, and batch progress polling runs only while a job is active. No decorative render loop was added.

## Not delivered or newly accepted

Automatic associative memory, cloud/encrypted storage, other runtime adapters, arbitrary active-workspace relocation, power-loss job replay, and media-link mount rename repair remain outside this release. A source beta is not an Apple-notarized public binary. Existing restart/remount evidence is narrow and preserved separately in the tested-boundaries reference.
