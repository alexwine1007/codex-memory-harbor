# 0.4.6-beta.3 — task identity and transparent branding

2026-10-13. This corrects blank Codex child-task titles that appeared as ids and rollout filenames, and the white matte around the public logo.

## Implementation boundary

- The normal scan uses Codex metadata, assigned child-task names and valid local display-label caches. It does not scan conversation bodies for descriptions.
- Visible rows request labels sequentially in batches of at most four. Each missing child description reads at most 2 MiB, with a 256 KiB decode limit per line. A trusted `NEW_TASK` recipient boundary is required; inherited parent conversation, analysis and raw tool output are excluded. An encrypted instruction stays encrypted; a plaintext outward report can supply the extract.
- Descriptions are redacted, compact original-text extracts, not generated interpretations. The detail view identifies the instruction/report source line. Missing or out-of-budget evidence remains explicitly unavailable.
- The local cache invalidates on size/mtime/ctime changes. Previously cached labels survive an unavailable source. In-place text updates do not change ordering, focus or selections. There is no idle timer or model request.
- The old task-report reader and recall extractor now recognize current-runtime assistant report records after the same task boundary. Recall extraction version is 2; no automatic whole-history backfill is started.
- Catalog schema 4 adds a display-label table without replacing existing metadata, fragments or manifests. Codex's database is read-only. Parking, restore and release rules are unchanged.
- One editable vector mark supplies the bilingual README and web UI. Transparent corners, a dark rounded tile, a purple-to-cyan harbor and a centered cream dot replace the white matte. A deterministic raster derivative supplies the macOS icon; old assets remain in Git for rollback.

- Strict installed app-signature verification and source/installed-Skill comparison passed. The actual installed native helper visibly displayed the three recovered task names and Chinese extracts; a legacy project task with no trustworthy report boundary displayed its indexed name and an explicit missing-description message.
- Browser verification exercised real local fixture APIs, task descriptions, report reading, description provenance, English/Simplified Chinese and the 390-pixel layout. No horizontal overflow or console warning/error was observed. Public screenshots contain disposable demo tasks only.

This remains a source beta, not an Apple-notarized public download. This iteration does not newly verify cold Codex resume, physical unplug/remount, automatic associative memory or cloud storage.
