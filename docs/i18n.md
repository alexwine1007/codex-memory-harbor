# Localization / 多语言

0.4.6-beta.1 includes English (`en`) and Simplified Chinese (`zh-CN`) for the workbench and native companion, plus matching README entrypoints. Unsupported UI locales fall back to English. Native UI follows macOS preferred languages; web UI initially follows the browser and can be changed in Settings. The browser stores only language and theme preferences, not task content.

## Web UI

Source: `skills/codex-memory-harbor/assets/dashboard/i18n.js`.

- Use named keys and placeholders, e.g. `t('selected', {history: 2, files: 3})`.
- `data-i18n`, `data-placeholder` and `data-aria` cover static labels and accessibility names.
- Add a language to the exported dictionaries and Settings options. Keep exactly the same keys and placeholder names.
- Test both languages at narrow widths, including confirmation, offline/error, progress, empty state and recovery.
- Language changes must not clear selection, alter object IDs, change paths or rewrite a frozen plan.
- Never translate user-authored titles, file paths, task reports or raw error evidence. Error explanations are localized; original errors remain in an explicit technical-detail section.
- No remote translation call or language model is used.

## Native macOS

English resources live in `macos/en.lproj/Localizable.strings`; the source fallback/development language is Simplified Chinese. `InfoPlist.strings` localizes removable-volume permission explanations. `scripts/build_macos_app.sh` copies resources into both app bundles before stable signing. Format placeholders (`%d`, `%@`) must retain their types.

The CLI/backend currently keeps stable Chinese error evidence and command names. UI translation does not silently change that API contract. Additional CLI locales and more community languages are future work, not claimed as complete.

## 中文贡献要点

先补全字典，再检查所有占位符、危险操作说明和小屏幕布局。不要翻译用户历史、文件名或路径；不要把“外盘在线可读”翻译成“离线无感”。现有两种语言不代表已经支持所有语言。回归入口：`python3 -m unittest discover -s tests -q`。
