# Memory Harbor 0.4.6-beta.2

## One window, one surface / 一个窗口、一层界面

- Removes the nested workbench card, its extra border, shadow and wide surrounding margins. Content uses the window surface directly.
- Hides the repeated native-window title while keeping macOS window controls and accessible window identity.
- 保留中英界面、项目树和全部安全操作；本次只修复双层窗口视觉，不改动迁移逻辑。

108 regression tests, including the disposable physical-volume test, passed locally. Both browser widths and the installed native helper are visually checked. The public screenshots use isolated demo data.

Source beta only: `./scripts/install_macos.sh` on macOS 13+. This is not a public Apple-notarized binary. Previous storage and recall boundaries still apply.
