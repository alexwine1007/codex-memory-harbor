# Memory Harbor 0.4.6-beta.3

- Readable child-task names and one-line descriptions replace ids and rollout filenames.
- Labels load only for visible rows and are cached locally; instructions and reports retain traceable provenance. Missing evidence is not guessed.
- Encrypted old task instructions remain encrypted. Current-runtime plaintext outward reports can be displayed after their own task boundary.
- The README, dashboard and Mac icon share a clean mark with transparent corners, without the white matte.
- Simplified Chinese and English interfaces remain supported. Storage safety gates are unchanged.

Source beta only; public downloadable/notarized Mac binaries are not included.
