# Memory Harbor 0.4.6-beta.1

English · 简体中文

## A smaller interface, the same verified storage contract

- Open directly into one usable workbench. Task history and on-demand project media share a project tree and a single review action.
- Search at the top; storage, language and appearance in Settings; restore/release behind docked-content management.
- English and Simplified Chinese UI and README. Native app resources follow macOS languages; web UI language/theme persist locally.
- Native desktop material via `NSVisualEffectView`, with reduced-transparency fallback. No decorative render loop or idle filesystem polling.
- No arbitrary 5 GB / 25-history selection cap. Backend admission, age (30 days), protection, open-handle, source, hash, receipt and volume gates remain.
- Terminal progress is exact; verified bytes and actual local-copy removals are reported separately.
- New pure-model/localization tests, source CI, contribution and privacy-aware issue guidance.

## 更直接、更简洁

打开即工作台，项目下合并历史与按需盘点素材；顶部查找，底部查看方案。设备、语言、外观放进设置，恢复与释放放进已停泊管理。支持中英界面与双语文档，桌面系统毛玻璃。取消 5 GB / 25 项推荐截断，但不放松任何迁移安全门。

## Installation and important limits

Source build on macOS 13+: `./scripts/install_macos.sh`. This release is a source beta, not an Apple-notarized public binary. No personal files are automatically moved by installation.

Keep local copies for first-time device/runtime validation. A mounted-drive original-path read is not automatic AI memory or offline availability. Cloud, semantic association, active-workspace moves, other runtime adapters and sudden-power-loss recovery are not delivered by this release.

Validation evidence is recorded separately in [0.4.6 verification](../verification/0.4.6-beta.1.md). Previous hardware/Runtime evidence remains in [tested boundaries](../../skills/codex-memory-harbor/references/tested-boundaries.md).
