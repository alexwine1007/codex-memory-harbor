# Memory Harbor｜前端体验基线

- 状态：草案 0.3
- 更新：2026-09-03
- 设计主题：未来记忆港
- 原型：[打开全中文交互原型](prototype/index.html)
- 交付边界：原型使用样例数据，不连接真实历史，不代表完整界面已上线

## 我们要做出的感觉

Memory Harbor 不该像磁盘清理器，也不该像工程监控后台。

它应该像一座安静、可信、带一点未来感的私人记忆港：用户一打开就知道自己做过的事情还在，需要时能够回来；只有真的出现风险或需要确认时，系统才要求用户处理。

第一眼要有吸引力，但不是靠堆满霓虹、参数和专业术语。科幻感来自空间、深度、光的路径和记忆之间若隐若现的联系；可信感来自清楚的状态、诚实的边界和可追溯的出处。

## 这次重做的判断

上一版“深空智能港”原型保留了产品安全逻辑，但呈现方式太像技术控制台：七个一级栏目、能力矩阵、C0–C3 和大量指标同时出现。它适合研发讨论，不适合作为用户每天打开的产品首页。

新版从产品北极星重新出发，不继续修补旧结构：

- 一级入口从七个收成三个：`港湾`、`找回记忆`、`安全停泊`；
- 设备、验证记录和偏好设置退到“更多”；
- Runtime、Adapter、哈希和路径只在用户追问依据时出现；
- 首页从“系统现在有哪些模块”改成“我的记忆现在怎么样”；
- 主视觉从指标仪表盘改成一片有记忆光点和归航路径的空间；
- 所有动作使用自然中文，同时保留安全停泊的精确含义。

## 三个一级入口

### 港湾

首页只回答三件事：

1. 我的历史还在吗？
2. 现在有没有事情需要处理？
3. 我想找回过去时，从哪里开始？

主文案采用“你走过的路，都还在这里”。中央记忆港展示在线历史的整体感，不用夸张动画假装系统一直很忙。下方只保留当前状态、存储位置和最近核验时间。

### 找回记忆

用户不必记住标题、文件名或任务编号，只需要说出还记得的部分。

结果默认很少，每条都说明：

- 为什么可能相关；
- 来自哪里；
- 原始记录是否在线；
- 可以只读原文，还是能回到原任务继续。

历史内容始终是证据，不是当前指令。

### 安全停泊

没有候选历史时，界面应该安静地说“今天不用整理”，而不是用巨大的 `0.0 B` 制造任务感。

需要停泊时，流程固定为：

1. 选出可以停泊的历史；
2. 先向用户展示完整方案；
3. 完成复制、持久化、长度、SHA-256 与独立回读；
4. 所有验证通过后，才允许释放本地实体。

不可逆动作不会和普通导航并排出现。

## 二级信息

以下内容仍然重要，但默认不占据主界面：

- 设备与连接：当前 Agent Runtime 和存储位置；
- 验证记录：检查范围、时间、结果和未证明边界；
- 偏好设置：停泊规则、隐私、本地索引与退出方式；
- 技术详情：Adapter 版本、路径、字节数、哈希与原始回执。

产品可以很简单，证据不能被删掉。二级信息是渐进披露，不是隐藏风险。

## 中文表达

- 默认使用简体中文；
- 对用户说“找回记忆”“回到这段工作”“今天不用整理”，不说“执行召回查询”“连续性核心无异常”；
- `Runtime`、`Adapter`、`SHA-256` 等术语只在技术详情中出现，并附中文解释；
- 底层异常映射成中文原因和下一步，原始技术信息保留在本地日志中；
- 不用“优化”代替真实的数据状态变化；
- “停泊”“保留本地副本”“释放本地副本”“恢复到本机”各自只表达一种动作。

## 视觉语言

### 气质

- 深色但不压抑；
- 未来感但不冰冷；
- 有空间感，不把页面切成密集表格；
- 高亮信息像远处信标，而不是每个按钮都发光；
- 让记忆本身成为主角，技术设施退到背景。

### 色彩

- 深海黑 `#050713`：整体背景；
- 归航紫 `#8B73FF`：品牌与主要动作；
- 记忆青 `#57DBFF`：路径、搜索与可读取状态；
- 安全绿 `#62EFC5`：已验证；
- 回忆粉 `#FF72BD`：少量情绪性强调；
- 警示琥珀 `#FFCF87`：需要复核，不与成功色混用。

### 动效

- 记忆光点可以轻微漂浮，鼠标移动可产生小幅空间视差；
- 查找、连接和验证可以用短暂光流表达；
- 空闲时不持续制造高频运动；
- 系统开启“减少动态效果”后关闭漂浮、呼吸与平滑滚动；
- 动效不能代替真实进度。

## 界面状态

必须拥有独立样例并分别验收：

- 历史全部在线；
- 没有历史或首次使用；
- 存储未连接；
- 部分历史不可访问；
- 权限被拒绝；
- 完整性校验失败；
- 正在停泊；
- 安全停止并保留本地实体；
- 找不到相关记忆。

绿色状态只能表达当前检查覆盖到的范围。没有完成断电、重挂载或跨版本验收时，必须明确写“尚未证明”，不能藏在帮助文档里。

## 当前交付与下一步

当前已经交付：

- 中文 Skill 与中文底层错误；
- 真实桌面状态卡的中文连续性摘要；
- 真实仪表盘的中文安全动作；
- “未来记忆港”静态交互原型。

尚未交付：

- 新原型与真实扫描、召回、停泊和恢复接口的连接；
- 全部失败状态的视觉夹具；
- 新界面的性能与无障碍验收；
- 第二个 Runtime Adapter。

下一阶段只有在视觉方向获得用户确认后，才把真实数据接入新界面。接入时不得顺带修改停泊安全合同。
