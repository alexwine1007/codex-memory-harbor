## 方向

- 按 Alex 2026-10-12 的反馈，将港湾和停泊合并为单一工作台，移除三段式导航与介绍首页。
- 打开即显示可选的候选内容，底部直接查看停泊方案。搜索在顶部，就地查找，不必换页面。
- 用项目树选择内容；文件清单、处理速度、哈希、验证记录在次级详情。
- 本机可用和存储连接缩成一行；桌面卡片直接打开同一工作台，不把候选数当成已验证释放量。
- 外盘在线只表达连接事实，不代表完整性已验证或所有研发可继续。
- 玻璃材质参考先前 Music Lab 的轻量玻璃原型；复用 22 px blur、1.45 saturation、顶边高光、暗边和无透明降级，
  不依赖 Pai 的代码、服务器、账号或音频。保留 Memory Harbor 紫色品牌。
- 没有定时扫描、粒子动画、模型或新框架。玻璃只在少量大表面上，内容不叠加过滤器。
