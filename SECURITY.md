# Security and data-safety reports

Memory Harbor is a beta filesystem tool. A copy check is not a general backup guarantee. Keep an independent backup of irreplaceable material.

Do not post credentials, complete session histories, personal project paths or exploitable sensitive details in public issues. If GitHub private vulnerability reporting is available on the repository, use its Security → Report a vulnerability flow. Otherwise open a minimal, non-sensitive issue asking for a private reporting channel; do not include the exploit or personal data until a private channel is agreed.

Please include the version, macOS version, filesystem type, the affected safety stage and a disposable reproduction. Preserve relevant receipts and local rollback files. Do not blindly retry, overwrite external targets, delete recovery files or weaken Gatekeeper to diagnose a failure.

The supported beta scope is macOS with the Codex adapter and an explicitly selected mounted external volume. Cloud storage, automatic associative recall, active-workspace migration, encrypted archives and other runtime adapters are not current security claims.
